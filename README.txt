BIZCONNECT - UPDATED DEMO

How to run:
1. Extract this ZIP.
2. Open index.html in Chrome/Edge, or use VS Code Live Server.
3. Open Businesses.
4. Each business now displays 3 products/services with prices.
5. Click + Add to put products into the cart.
6. Open Cart, change quantities, and submit the payment/order form.
7. Payment methods shown are UPI, Debit/Credit Card, and Cash on Delivery/Pay at Service.
8. Register Business -> Submit Business now shows a success message and stores the registration in browser localStorage.

IMPORTANT:
This is a frontend demonstration. It records demo orders locally in the browser; it does NOT charge real money.
For real payments, connect a payment gateway such as Razorpay/Stripe with a backend and server-side verification.
